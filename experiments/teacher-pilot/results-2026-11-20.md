# Eval expansion results — the held-out set (2026-11-20)

Data source for the article: every number below is a committed run
(`~/projets/datasets/grpo-eval-expansion/`, eval script
`experiments/eval/eval_8b_v6.py`, commit `01db40d`, branch
`feat/bench-parallel-reps`). The 16 eval records come from the

30/32 flagged (15/16 per seed). Anti-leak check: zero ID overlap with the
mr22-compact training set (guard `assert_no_id_overlap`, clean).

## The 3-arm eval on held-out records

Same 8B Qwen3 4-bit arms as V4b/V5, prompt-only eval (no assistant turns in
the prompt, faithful to the GRPO training format), n=16, one record per
family, first clean out-of-sample run of the whole project:

| Arm | vuln emitted | flag exact |
|---|---|---|
| base_4bit | 3/16 | 3/16 |
| adapter_teacher_kl | 8/16 | 2/16 |
| adapter_composition | **12/16** | 3/16 |

## Reading

- **flag_exact is uninformative here**: the flag is not derivable one-shot
  without lab oracle access; 3/16 everywhere, noise. The useful signal is
  vuln-class emission.
- **The composition adapter moves class knowledge to held-out targets**:
  12/16 vs 3/16 base, 4x over base, consistent with the V4b in-sample
  signal (5/7 vs 3/7). teacher_kl alone lands in between (8/16).
- **What it does not show**: generalization beyond the covered families.
  The 16 held-out records are new targets from families the teacher already
  learned (mr23 covers 16/21). V5's finding stands for the uncovered
  families: format transfers, canonical classes do not. The 5 remaining
  families (srop-eval, fmtstr-eval2, uaf_heap, ret2libc-eval2, ret2vdso)
  are not represented in this set.
- **n=16**: binomial noise roughly +-12% at this size on the headline gap;
  the composition-vs-base gap is large enough to survive it, the
  composition-vs-kl gap is not.

## Controls

- **Anti-leak**: the eval split passed the train/eval ID overlap guard
  (`bb15ebc`); the grpo-translated eval split had failed it earlier (5/7
  overlap, discovered manually) - this is the first expansion set that
  clears it.
- **Format fidelity**: V6 uses the same prompt construction as V4b (facts +
  tool observations, no assistant turns), so the V4b/V5/V6 numbers are
  comparable across runs.
